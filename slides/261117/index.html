簡介· 02

State, Action, Reward

名字意思在神盾盃
State \(s_t\)Agent 看到的東西
（也叫 Observation）		182 個數字：自己的高度、速度、姿態；敵機相對我的位置和速度 …
Action \(a_t\)Agent 能做的事4 個數字：油門、要拉幾 G、每秒滾轉多快、方向舵
Reward \(r_t\)這一個 step 做得多好1 個數字，每 0.1 秒給一次

RL 沒有「每一步的正確答案」，只有分數：要學的是 Policy，讓分數加起來最大。

簡介· 04

Reward 的種類

類型什麼時候給例子神盾盃
結果一局結束時圍棋：贏 +1、輸 −1贏 +10、輸 −10
事件發生某件事時遊戲：吃到金幣 +1擊落 +5、自己墜機 −2
每一步每個 step 都給離目標越近，分數越高機頭對準敵機、位置好就加分
  • 只有「結果」的 Reward 很少也很晚：幾百手裡只有最後一手有分數，贏了也不知道是哪幾手的功勞。這叫 sparse reward。
  • 「每一步」的 Reward 讓 Agent 好學很多。
簡介· 05

Reward vs. Return

  • Agent 要讓 Return 最大，不是讓眼前的 Reward 最大。
  • 所以它願意先做 Reward 很低的事，去換後面的大分。
  • 越後面的 Reward 算得越少，這叫 discount：\(G_t = r_t+\textcolor{#b23a2a}{\gamma}\,r_{t+1}+\textcolor{#b23a2a}{\gamma^2}\,r_{t+2}+\cdots\)，\(\gamma\) 在 0 到 1 之間。

先花十幾秒繞到敵機後方，這段時間幾乎沒有分數；繞到了才打得到。只看眼前 Reward 的 Agent，不會去繞。
我們用 \(\gamma = 0.995\)（一個 step 0.1 秒）：20 秒後的 Reward 剩 37%，60 秒後剩 5%。

簡介· 06

Policy

Policy 不只輸出一個 Action，而是輸出 Action 的機率分布：\(a_t \sim \pi_\theta(\,\cdot\mid s_t)\)，\(\theta\) 是 neural network 的權重。

  • 輸出是一個常態分布 \(\mathcal{N}(\mu,\sigma^2)\)：μ 是它現在覺得最好的 Action；σ（標準差）是分布有多寬，σ 越大，抽到的 Action 差得越多。
  • 每次從分布裡抽一個 Action，所以會試到沒做過的，才有機會發現更好的。
  • 學習 ＝ 把好的 Action 的機率調高。

訓練時從分布裡抽一個來飛；
比賽時直接用 μ（中間那個）。

簡介· 07

Advantage：跟平常比

每個 Action 的 Return，先減掉「平常的分數」：

拿到的 Return減掉平常的 4 分機率
Action A3−1調低
Action B5+1調高
Action C40不動

「平常的水準」叫 Baseline。

但「平常」要看局面：

我咬住對方的尾巴

預期 +8，結果 3：差 5 分

對方咬住我的尾巴

預期 −5，結果 3：好 8 分

  • Value \(V(s)\)：局面的分數。從這個局面開始，預期能拿多少 Return，也就是跟著局面變的 Baseline。
  • Advantage \(\hat A\)：Action 的分數＝實際拿到的 − Value 預期的。正的以後多做，負的以後少做。
簡介· 08

Actor–Critic

  • Actor 是 Policy 的 network；Critic 是 Value 的 network。
  • Critic 只在訓練時用。比賽時只需要 Actor。
  • 我們用的 PPO 也是一種 Actor–Critic，多一條規則：每次更新，Policy 不能一次改太多。

我們的 Actor 和 Critic 各是一個 neural network，輸入都是 State 的 182 個數字，各約 229 萬個參數。

Agent 會鑽漏洞

Agent 會把你給的 Reward 做到極致，包括你沒想到的方式。

假設：每次從敵機下方
越到上方就 +1
→
Agent 學會一直飛高飛低刷分，
分數很高，但打不贏

這叫 reward hacking。

OpenAI Hide and Seek（2019）

躲的一方學會把門堵起來、把斜坡鎖走 → 找的一方發現 box surfing：站在箱子上，騎著箱子越過牆；還有斜坡彈射：拿斜坡撞牆，把自己彈過去。都是物理引擎的漏洞。
影片：youtube.com/watch?v=Lu56xVlZ40M

我們輸贏、擊落、每個 step 的位置優勢分都有給。早期的 Agent 學到：開局掉頭逃跑、時間到靠比分贏。練 3 億 steps，一次都沒擊落過。

實作· 02

Self-play 與 Opponent Pool

對打時，對手也是 Environment 的一部分。

  • Self-play：跟自己打。自己變強，對手也跟著變強，不用另外找對手。
  • 只跟最新的自己打有兩個問題：學會新招就忘了怎麼對付舊招；而且只會打「跟自己很像」的對手。
  • Opponent pool：把過去的自己和不同風格的對手留下來，每一局從裡面抽一個。

假設的例子：如果目標只有「贏」，可能養出一個總是引誘對手墜機的 Policy；只要訓練時的對手都躲不掉，它的勝率就很高。但比賽時對手如果剛好有防墜機的做法，這招完全沒用。
所以對手要夠多樣。我們的對手池裡有：手寫規則的對手、過去存檔的自己、同時在訓練的其他 seed。
